EXODUS Keyboard Shortcuts

General

Keys Name Description
Ctrl+Enter or F9 Save/Yes/Start Commit any screen or popup
Esc or F8 Cancel/No/Stop Close any document or popup
F2 Edit/Home/End Edit the current field instead of replacing it
Alt+M Menu Open the menu. Press letters or cursor keys to select menu items
F7 Popup Options for the current item
F6 Link Open related screen for current item

Documents

Keys Name Description
Alt+N New Start a new document
Alt+O Open/Search Open an existing document — Search/Browse/List
Alt+C Close Close the current document
Alt+E Edit/Release Edit document / Release document to other users
Alt+P Print/Send Print/Send the current document
Alt+L List Get a list of the documents
Alt+Home Home Move to the first field on the document
Alt+End End Move to the last field on the document
Alt+↑ Alt+↓ Scroll Page Pan the window about one screen up/down. Alt+↓ on a drop-down still opens options
Alt+← Alt+→ Scroll / History On wide forms: pan left/right about one screen. Otherwise: browser history back/forward
Alt+0 Alt+1 etc. Button 0–9 Special buttons per form

Rows and Columns in Tables

Keys Name Description
Ctrl+Insert or Ctrl+I Insert Row Insert a new row
Ctrl+Delete or Ctrl+D Delete Row Delete the current row (or Ctrl+Shift+D)
Alt+Y Copy Down Duplicate the data from the same column in the row above
Ctrl+G Go To Go to line number xx / Show current line number
Ctrl+Home First Row/Column Go to the first row and column in a table
Ctrl+End Last Row/Column Go to the last row and column in a table
